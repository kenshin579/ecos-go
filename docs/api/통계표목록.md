# 통계표목록 (StatisticTableList)

> `GET https://ecos.bok.or.kr/api/StatisticTableList/{API_KEY}/{요청유형}/{언어구분}/{시작건수}/{종료건수}/{통계표코드}`

ECOS 에서 서비스되는 통계표 목록을 제공한다. 부모·자식(그룹·통계표) 트리 구조이며,
`SRCH_YN=Y` 인 행이 실제 데이터 조회(StatisticSearch)가 가능한 통계표다.

## 기본 정보

| 메서드 | 출력포맷 | 비고 |
| --- | --- | --- |
| GET | JSON, XML | 요청유형 path 인자로 선택 |

## 요청 인자 (path segment 순서)

| 위치 | 인자 | 필수 | 값 설명 |
| --- | --- | --- | --- |
| 1~6 | 공통 인자 | Y | [README 공통 규약](README.md) 참고 |
| 7 | 통계표코드 | N | 지정 시 해당 통계표 1건만 조회 (예: `102Y004`) |

## 응답 필드 (`StatisticTableList.row[]`)

| 필드 | 명칭 | 설명 |
| --- | --- | --- |
| P_STAT_CODE | 상위 통계표코드 | 트리 부모 노드. 최상위 행은 `*` |
| STAT_CODE | 통계표코드 | StatisticSearch·StatisticItemList 등에서 사용하는 키 |
| STAT_NAME | 통계명 | 번호 체계 포함 (예: `1.1.1.1.1. 본원통화 구성내역...`) |
| CYCLE | 주기 | A/S/Q/M/SM/D. 그룹 노드는 `null` |
| SRCH_YN | 검색 가능 여부 | `Y` 면 StatisticSearch 로 데이터 조회 가능, `N` 이면 트리 그룹 노드 |
| ORG_NAME | 출처 | 대부분 `null`. 그룹 노드는 항상 `null`이며, `SRCH_YN=Y`인 통계표라도 값이 비어 있는 경우가 많다(실측: 834건 중 1건만 값 존재, 예: `102Y001` → `한국은행`) |

## 샘플

### 기본 조회 (요청유형=json, 시작~종료건수=1~10)

요청:

```
GET https://ecos.bok.or.kr/api/StatisticTableList/{API_KEY}/json/kr/1/10/
```

응답 (발췌, 전체 10건 중 앞 3건 — `list_total_count`는 전체 834건 기준):

```json
{
  "StatisticTableList": {
    "list_total_count": 834,
    "row": [
      {
        "P_STAT_CODE": "*",
        "STAT_CODE": "0000000001",
        "STAT_NAME": "1. 통화/금융",
        "CYCLE": null,
        "SRCH_YN": "N",
        "ORG_NAME": null
      },
      {
        "P_STAT_CODE": "0000000001",
        "STAT_CODE": "0000000620",
        "STAT_NAME": "1.1. 통화/유동성(신지표)",
        "CYCLE": null,
        "SRCH_YN": "N",
        "ORG_NAME": null
      },
      {
        "P_STAT_CODE": "0000000620",
        "STAT_CODE": "0000000621",
        "STAT_NAME": "1.1.1. 본원통화",
        "CYCLE": null,
        "SRCH_YN": "N",
        "ORG_NAME": null
      }
    ]
  }
}
```

최상위 행(`0000000001`)의 `P_STAT_CODE` 는 `*` 이며, 위 3건은 모두 트리 그룹 노드(`SRCH_YN=N`, `CYCLE=null`)다.

### 통계표코드 지정 조회 (위치 7 인자 사용)

`102Y004`(본원통화 구성내역, 평잔·계절조정계열)를 지정하면 해당 1건만 반환된다.

요청:

```
GET https://ecos.bok.or.kr/api/StatisticTableList/{API_KEY}/json/kr/1/10/102Y004
```

응답:

```json
{
  "StatisticTableList": {
    "list_total_count": 1,
    "row": [
      {
        "P_STAT_CODE": "0000000622",
        "STAT_CODE": "102Y004",
        "STAT_NAME": "1.1.1.1.1. 본원통화 구성내역(평잔, 계절조정계열)",
        "CYCLE": "M",
        "SRCH_YN": "Y",
        "ORG_NAME": null
      }
    ]
  }
}
```

이 행은 `SRCH_YN=Y`, `CYCLE=M`(월) 이므로 `STAT_CODE=102Y004` 로 StatisticSearch 조회가 가능하다.
